# DocVerify — Integrated Platform

Blockchain-based document verification — all three student contributions integrated into one runnable project.

---

## Quick Start (3 terminals)

### Terminal 1 — Hardhat Local Blockchain
```bash
cd E:/doc-verify-app
npm run node
```
Starts a local Ethereum node at http://127.0.0.1:8545 (chainId 31337).
Copy one of the printed private keys into MetaMask as a test account.

### Terminal 2 — Deploy Smart Contract
```bash
cd E:/doc-verify-app
npm run deploy:local
```
Deploys DocumentRegistry and automatically writes the address to `frontend/.env`.

### Terminal 3 — Frontend
```bash
cd E:/doc-verify-app/frontend
npm run dev
```
Opens at http://localhost:3000

---

## MetaMask Setup (one-time)

1. Open MetaMask → Add Network → Add manually:
   - Network Name: `Hardhat Local`
   - RPC URL: `http://127.0.0.1:8545`
   - Chain ID: `31337`
   - Currency: `ETH`
2. Import a test account:
   - In Terminal 1 output, copy any private key printed by Hardhat
   - MetaMask → Import Account → paste key
